Tested output, not a promise

What does an editable HTML to Figma import actually preserve?

This is a real comparison from the html2design test workspace. The source is a complex, seven-screen HTML fixture. The result was imported into Figma as editable layers, then captured without retouching.

Tested July 14, 2026 · Editable workflow · Images below are original evidence artifacts

Preserved in this fixture

The structure remains recognizable and editable

  • Seven screen frames and their main content hierarchy
  • Text content, font sizing hierarchy, colors, and alignment
  • Background fills, cards, borders, corner radii, and spacing
  • Local raster images, icons, and the major visual grouping

Visible differences

Editable mode is not a pixel-perfect guarantee

  • The imported canvas omits the browser page title and outer presentation styling.
  • One remote image is unavailable and appears as a placeholder.
  • Some text wraps or clips differently because browser and Figma font metrics differ.
  • Long screens are represented at their captured frame size, not as interactive scroll views.

How to judge the result

Choose the mode by what you need after import

Need the closest visual reference?

Use URL Pixel mode. It captures lossless raster tiles, so individual text and controls are not editable.

Need to redesign the page?

Use Editable mode or manual HTML import. Expect to check fonts, image loading, SVGs, and complex effects.

Need production-ready components?

Treat the import as a starting point. Auto Layout, Components, Variants, Variables, and interactions require design work.

Reliability evidence

Automated tests cover parsing, capture, URL import, and the plugin UI

The July 14 test run passed 75 unit tests and 11 browser end-to-end tests. Measured unit coverage was 94.10% statements, 83.76% branches, 98.61% functions, and 97.27% lines. The suite checks HTML security, tree construction, style transformation, icon handling, URL validation, capture analysis, timeouts, stale responses, and packaged UI flows.
