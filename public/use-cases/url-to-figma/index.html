Choose the output

Pixel fidelity or editable structure

Pixel mode

Lossless visual capture

The rendered page is imported as lossless raster tiles. Use it when matching the browser appearance matters more than editing each element.

  • ✓Highest visual fidelity
  • ✓Useful for redesign overlays and references
  • ✓Text and controls are not individually editable

Editable mode

Native Figma layers

html2design extracts rendered text, images, layout, and computed visual styles into Figma nodes. Use it when you need to inspect or change the result.

  • ✓Editable text, frames, shapes, and images
  • ✓Canvas, video, WebGL, and complex SVG may be rasterized
  • ✓Best effort; complex pages can require cleanup

Workflow

How to convert a URL to Figma

  1. 01

    Open the plugin

    Run html2design inside the Figma file where you want the capture.

  2. 02

    Enter a public URL

    Use an HTTP or HTTPS page that a remote browser can reach without private network access.

  3. 03

    Choose a mode

    Select Pixel for visual matching or Editable for native Figma layers.

  4. 04

    Capture and review

    Place the result on the canvas and inspect fonts, lazy content, and complex media.

Works best with

Public, browser-rendered pages

Marketing sites, documentation, blogs, public product pages, and rendered application screens are good candidates. The capture service preserves SVG geometry where possible and can rasterize browser-only regions while keeping surrounding content editable.

Known limits

Some pages need manual import

Login state, bot protection, DRM, unusual lazy loading, unavailable fonts, private networks, and browser effects can prevent a complete capture. For localhost, authenticated tools, or confidential HTML, use the manual HTML workflow.

Data handling

URL capture uses a remote browser

The public URL is sent through html2design infrastructure so a remote browser can render it. This differs from manual paste/file import, where the supplied HTML is not sent to the URL-rendering service. Do not use URL import for confidential or private-network content.

Questions

URL import FAQ

Can I import localhost by URL?

No. The URL service blocks localhost and private network addresses. Copy the rendered HTML and use manual import instead.

Is Editable mode pixel-perfect?

It is best effort. Browser CSS, Figma nodes, fonts, filters, canvas, video, and interaction states do not map one-to-one. Choose Pixel mode when visual matching is the priority.

Will the result use Auto Layout?

No. html2design reproduces the captured state with frames and positioned layers. It does not automatically generate Auto Layout, Components, Variants, or Variables.

Why is content missing from a capture?

Common causes include login requirements, bot protection, lazy-loaded content that never appeared, DRM, unavailable fonts, or a capture size or time limit.
