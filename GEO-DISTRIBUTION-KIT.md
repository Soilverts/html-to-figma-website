**Title**
HTML to Figma: Import a Website URL or HTML

**Short description**
Import pasted HTML, an HTML file, or a public website URL into Figma. Choose lossless Pixel capture for visual reference or Editable mode for native text, frames, shapes, and images. Editable output is best effort and complex pages can require cleanup. No browser extension is required.

- Public URL: Pixel or Editable mode
- Localhost/private source: manual HTML or file import
- Pixel mode: highest visual fidelity, not element-level editable
- Editable mode: native layers with documented browser/Figma limitations

## Reddit discussion draft

**Title**
I tested editable HTML-to-Figma import on a long jewelry storefront. Here are the misses too.

**Body**
Disclosure: I work on html2design. We tested a 4,321 px jewelry storefront at a 1,425 px desktop viewport and published the exact noindex input beside the unretouched Editable mode result. All 16 visible image layers and 57 text layers were present in the Figma output. Some navigation text wrapped differently because browser and Figma font metrics are not identical, image-fill crops shifted slightly, and the result still needs design-system cleanup. Pixel mode is a better fit when visual reference matters more than editable elements. The evidence, input, screenshots, hashes, and known differences are here: https://html2design.com/result-quality. I would value examples that fail in different ways so we can expand the fixture set.
