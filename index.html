Import websites and complete HTML documents into Figma

html2design converts a public website URL or supplied HTML document into Figma. Pixel mode captures the rendered page as lossless raster tiles when visual fidelity matters most. Editable mode maps supported text, images, fills, borders, shadows, and measured layout into native Figma layers for inspection and editing.

Use public URL capture for accessible websites, marketing pages, and visual references. For localhost, authenticated products, staging builds, email templates, and individual components, supply an HTML file or markup that includes its required inline styles, style blocks, or reachable stylesheets. Isolated outerHTML does not contain external CSS or computed-style values.

A verified result-quality example documents the input page, output screenshots, and layer evidence. The guide explains the complete import process, while the comparison pages describe when Pixel capture, editable conversion, screenshots, or manual reconstruction fit a project.
